## Inventory boundaries

The inspection used Docker state, mounts, Compose labels, selected non-secret settings, the local Caddyfile, and Komodo's read-only API. Application roles are identified from their images and project documentation. App logins, external tunnel routes, monitor settings, database recovery, and end-to-end availability were not tested.

Stopped containers included `caddy-caddy-1`, `server_wiki`, and an older `cloudflared` instance named `vibrant_shirley`. They are not counted in the forty-four running containers.

Refresh this reference after deployment changes; the counts and states are a dated snapshot.
