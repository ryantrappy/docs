These containers support media requests, downloads, library automation, viewing history, and file cleanup. The snapshot was checked on **2026-09-28**.

## Stack ownership and access

Komodo confirms the six-service `arr_stack` and single-service `watcharr` stacks. qBittorrent's labels point to the older `/data/compose/68` Compose project.

Maintainerr, MeTube, Czkawka, and iSponsorBlockTV have no Compose labels. Their original management source is not established by those labels.

Caddy routes `ombi.ryantr.app` publicly. It guards `radarr`, `sonarr`, `sab`, `watcharr`, and `maintainerr` under `.ryantr.app` for LAN access. Routes and service details appear below.

[Plex Media Server](/services/plex) runs directly on Ubuntu as `plexmediaserver.service` and responds at `192.168.1.236:32400`. Its dedicated reference documents the Movies, TV Shows, and Photos library roots, metadata, and maintenance. Tautulli and Maintainerr may integrate with Plex, but their application configuration was not inspected.

## Port mappings to verify

| Container | Observed host → container mapping |
| --- | --- |
| `arr_stack-ombi-1` | `3579 → 5055/tcp` |
| `arr_stack-overseerr-1` | `5055 → 3579/tcp` |
| `arr_stack-sonarr-1` | `8112 → 8112/tcp`; `8989/tcp` is exposed without a host binding |

These unusual mappings are recorded exactly as Docker reports them. Check the configured application listeners and browser responses before changing them. Caddy currently targets host ports 3579 for Ombi and 8112 for Sonarr. This inventory did not change or test those listeners.

qBittorrent publishes 8989 and 6881; 6881 is bound over TCP and UDP. MeTube publishes 8085, Czkawka 5800, and Tautulli 8181. No Caddy route for those services or Overseerr was found.

## Download and library storage

SABnzbd uses `/media/internal/fourTbRed/complete` and `/media/internal/fourTbRed/incomplete`. Radarr and Sonarr share the completed-download path and mount `/media`.

qBittorrent downloads live at `/media/internal/twelveTb/torrent`. MeTube writes into `/home/trappserver/Documents/metube`.

Czkawka mounts `/media` writable at `/storage`; file operations in the app act on those host files.

Preserve application configuration and the media/download files you need. A configuration backup does not include files elsewhere under `/media`.

Use [Service operations](/operations/services) for maintenance and backup planning.
