This reference covers rankings, recipes, Homebridge, and the running TeslaMate support services, checked on **2026-09-28**.

## Fantasy football rankings

[Rankings](https://rankings.ryantr.app) is a public Caddy route to host port 3030. Komodo manages `fantasy-rankings` from the linked `fantasy_rankings` repository at `/etc/komodo/repos/fantasy_rankings/docker-compose.yml`.

The API reports source repository `ryantrappy/Fantasy-football-rankings-studio` and deployed revision `8565438`. The app image is built locally as `fantasy-rankings-app:local`.

MongoDB stores data at `/home/trappserver/Documents/fantasy_rankings`. The app mounts `fantasy-rankings_codex-home` at `/app/.codex`; its contents were not inspected.

The app restart policy is **no**, while MongoDB uses `unless-stopped`. A reboot or process exit can leave the app stopped until it is started again. This inventory did not change that setting.

## Tandoor recipes

[Recipes](https://recipes.ryantr.app) is a public Caddy route to host port 8686, mapped to container port 8080. The older `tandoor` project labels point to `/data/compose/33`.

Mounts preserve `/home/trappserver/Documents/tandoor/mediafiles` and `staticfiles`. No Tandoor database container appears in the running snapshot. Its database engine and location were not established; identify that storage before treating these directories as a complete recovery set.

## Homebridge

[Homebridge](https://homebridge.ryantr.app) is a LAN-only Caddy route to `127.0.0.1:8581`. Homebridge uses host networking and stores state at `/home/trappserver/Documents/homebridge`.

No Compose labels are present. Plugins, pairings, and the UI listener were not inspected. Preserve its state when changing deployment.

Home Assistant is configured in Caddy at `192.168.1.254:8123`, outside this host's Docker inventory. Its LAN page responded successfully, and UniFi reported it online. See [Homelab devices](/infrastructure/devices) for Home Assistant and the SMLIGHT coordinator; their integrations and backup configuration remain unverified.

## TeslaMate support services

The `teslamate` project has Grafana, PostgreSQL 13, and Mosquitto running. Grafana publishes 3000; database and MQTT ports are not host-published. Labels point to `/data/compose/4`.

**No TeslaMate logger container appears in the running or stopped host snapshots.** These support services do not establish that vehicle data collection is active. Check whether the logger runs elsewhere before assuming the stack is complete.

Preserve the named volumes for database, Grafana, and Mosquitto data/configuration. No TeslaMate Caddy route was found.

Use [Service operations](/operations/services) for maintenance.
