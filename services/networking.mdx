These containers support HTTPS routing, Cloudflare connectivity, DNS, and network monitoring. The running-container snapshot was checked on **2026-09-28**.

## Proxy, tunnel, and dynamic DNS

[Caddy setup](/infrastructure/caddy) documents hostnames, Cloudflare certificates, LAN access, and automatic UniFi DNS additions.

Komodo confirms `cloudflared` and `cloudflare-ddns` as running stacks. Both use host networking and have no Docker mounts. Tunnel destinations and selected DNS records were not queried. Retain their deployment configuration and credentials when migrating.

A running tunnel connector does not establish that every Caddy hostname also has a tunnel route.

The host also runs native `ddclient`; its protected configuration was not inspected. See [Native host services](/services/host#dynamic-dns). The [Homelab devices](/infrastructure/devices) page records the UniFi gateway, switches, access points, and reported uplinks.

## Blocky migration

Blocky is **still running** and reports healthy in this snapshot. It publishes DNS over TCP and UDP 53 and host port 4001 to container port 4000.

The migration notes identify UniFi at `192.168.1.1` as the primary LAN DNS server. Blocky at `192.168.1.236` remains a compatibility resolver for old DHCP leases and manually configured clients, forwarding to the gateway. Review client migration before retiring it. See [Caddy's migration context](/infrastructure/caddy#blocky-migration-context).

Its configuration is mounted from `/home/trappserver/Documents/blocky/config.yml`.

## Network Optimizer

The `network-optimizer` project includes the main application, speed test service, and InfluxDB. Compose labels point to `/data/compose/67/docker-compose.yml`; the project is not among the nine running stacks returned by Komodo's API.

The main application uses host networking. Its UI listener was not verified. The speed test publishes 3005; InfluxDB publishes 8086.

Network Optimizer provides UniFi monitoring and analysis. See the [project documentation](https://github.com/Ozark-Connect/NetworkOptimizer). This inspection did not audit or change the network.

Retain the application data, InfluxDB data/configuration, Blocky configuration, and deployment definitions. The SSH key directory is credential storage. The Caddy page lists its certificate and configuration mounts.

Use [Service operations](/operations/services) for routine maintenance.
