## Keep these handy

- **Change deployments in Komodo.** Use the saved stack definition, or the linked repository for rankings. Portainer and Watchtower are stopped. See [service updates](/operations/services#update-a-service).
- **For a LAN hostname that fails, check DNS first.** Query `192.168.1.1`; internal service names should resolve to `192.168.1.236`. The [DNS and proxy checks](/operations/services#separate-dns-proxy-and-application-failures) help isolate the cause.
- **If Plex media disappears, check the disk mounts.** Keep [Plex library paths](/services/plex) and [storage and recovery notes](/infrastructure/host-reliability) nearby.
- **If Komodo itself is down, use its independent bootstrap Compose file.** Location: `/home/trappserver/Documents/komodo/komodo/mongo.compose.yaml`. See [deployment ownership](/operations/services#find-the-owning-deployment) before recreating services.
