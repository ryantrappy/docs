Use this site as the operating reference when setting up an application, changing a stack, or diagnosing a failure. Keep it current as the homelab changes so the next task starts from documented configuration.

Komodo, Portainer, and several administration routes require LAN access through Caddy. A hostname listed in the configuration does not guarantee its application is responding.

## What belongs in these docs

Document each service's purpose, access path, deployment source, dependencies, persistent storage, and routine maintenance. Record migration decisions and verification dates beside the relevant configuration.

Keep credential values in their credential stores. These pages can name an environment variable or configuration file without containing its secret value.

The [inventory](/services/overview) distinguishes runtime facts from details that still need verification. Host configuration and deployment definitions remain the source of truth.
